# BroWarz Documentation Index

- `corporations.md` — Lore and identity reference for the four playable corporations: backgrounds, mottos, colors, strengths, preferred units, signatures, and diplomatic doctrine.
- `design.md` — Overall game design document: vision, factions, units, maps, economy, combat, networking, AI, testing, security, and implementation status.
- `diplomacy.md` — Specification for temporary in-match alliance sides: graph model, proposal states and actions, host-authoritative flow, effects, functions, and limitations.
- `factories.md` — Catalog of production buildings with tiers, footprints, HP/costs, required builders, outputs, per-building thumbnails, and a summary table.
- `npc.md` — Guide to the four AI-only NPC factions (IDs 4–7): identities, banners, theme music, unique units, combat modifiers and AI-only selection rules.
- `map_editor_ui_plan.md` — Phased UX/UI plan for the map editor, covering the shipped structured-error workflow and future workspace/file/validation enhancements with acceptance criteria.
- `maps.md` — Reference for built-in maps, terrain passability, seeded generation, custom-map handling, and hex movement.
- `roadmap.md` — Verified milestone summary, pending v0.1.3 work and deferred future ideas; the detailed step checklist was retired after every item was confirmed live-wired.
- `units.md` — Illustrated unit roster by domain with faction sprite thumbnails, roles, and allied-behavior rules.

Supporting image assets live in `docs/map_thumbnails/` (built-in map previews), `docs/thumbnails/` (per-faction unit renders, including the AI-only NPC roster's native thumbnails), and `docs/thumbnails/buildings/` (per-building renders) and are generated by the tools documented in [`../scripts/readme.md`](../scripts/readme.md). AI-only NPC banners live in `assets/banners/` and their theme WAVs in `assets/music/`; see [`npc.md`](npc.md).
